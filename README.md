
# ⚡ WattWise – Electricity Bill Estimator

A simple, user-friendly web application that estimates electricity bills based on meter readings and applicable tariff calculations.

🌐 **Live Demo:** https://stanelyj48.github.io/Power-Bill-Estimator/

## 📌 About the Project

WattWise is a browser-based electricity bill estimation tool built to make electricity cost calculations easier. Users can enter their meter readings and view an estimated bill based on the tariff structure implemented in the application.

## ✨ Features

- Enter current electricity meter readings.
- Calculate electricity consumption.
- Estimate electricity charges using configured tariff slabs.
- Display an estimated electricity bill.
- Simple and responsive user interface.
- Works directly in a web browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/StanelyJ48/power-bill-estimator.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional installation is required.
